# Eprezto Coding Assessment

Projecto de demostración para la empresa Eprezto.

## Características

- Pólizas ordenadas por precio
- Estilos mediante TailwindCSS
- Diseño responsive
- Redux como patrón de gestión global de estado
- Cargar datos desde un archivo JSON a través de LowDB

## Ejecución local

1. Instalar:

   - [Node.js](https://nodejs.org/es/download/)

1. Clonar el proyecto:

   ```bash
   git clone https://github.com/AloisCRR/eprezto-coding-assessment.git
   ```

1. Acceder al directorio del proyecto:

   ```bash
   cd eprezto-coding-assessment
   ```

1. Instalar las dependencias:

   ```bash
   npm install
   ```

1. Iniciar el proyecto en modo development:

   ```bash
   npm run dev
   ```

   Accede a [http://localhost:3000](http://localhost:3000) para ver el proyecto desde el navegador.
